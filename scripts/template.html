Clef at a glance

Models
@cf/cloudflare/clef (27B) and @cf/cloudflare/clef-flash (9B)
What it does
Takes a state plus typed questions (noul, choice, score) and returns a probability for every allowed answer. No text generation.
Input
Text, JSON, images or video, with a 65,536-token context.
Pricing
$0.24 (Clef) and $0.09 (Clef-flash) per million input tokens on Workers AI.
Weights
Open, Apache 2.0, on Hugging Face.
API
Jev / System One compatible request and response shape.

Per Cloudflare's model page and launch post, Oct 1, 2026.

Workers AI

worker.ts

const res = await env.AI.run("@cf/cloudflare/clef-flash", {
  model: "clef-flash",
  state: "Checkout has been failing for every customer.",
  questions: {
    urgent: { type: "noul",
      instructions: "Is this support request urgent?" },
    team: { type: "choice",
      instructions: "Which team should handle it?",
      criteria: {
        billing: "Payments and refunds",
        technical: "Outages and errors",
      } },
  },
});
// res.answers.team -> choice + per-option probabilities
